Healthcare · Web App

MA Repay: Loan Repayment Platform for MLCHC

MLCHC and the Executive Office of Health and Human Services (EOHHS) run the MA Repay Program, which helps direct-care providers repay student loans so they stay in underserved communities. As the program grew, Excel-based tracking became slow and error-prone, so I designed a scalable web platform that automates applications, tracking and reporting.

  • Role UX/UI Designer
  • Tools Figma, FigJam
  • Platform Web app
25%faster user workflows through simpler navigation and clear data visualization
30%quicker design-to-development handoff with documented components

02
Non-profit · Web App

DOR Foundation: Scholarship Management System

Running a scholarship program means many people working on each student: the applicant, the volunteers who counsel and verify, and the admins who decide. I designed one web platform for all three. Students apply online and book interview slots, volunteers record counselling, home-visit and in-person verification, and admins review applications, manage seats and track every step.

  • Role UX/UI Designer
  • Tools Figma, Figma Make
  • Platform Web app
3user portals for students, volunteers and admins, each with its own dashboard
4-stepguided application: personal, academic, family & finance, then review and submit

03
QA · SaaS Platform

AutoFlow Studio: No-Code Test Automation Platform

Writing and maintaining test scripts slows QA teams down, and release decisions often rely on gut feeling. I designed a platform where testers record a test by doing it once, AI auto-heals tests when the app changes, and a release confidence score gives a clear GO or NOT GO, with the reasons behind it.

  • Role UX/UI Designer
  • Tools Figma
  • Platform Web app (SaaS)
0lines of code to create a test: record the flow once and it becomes automation
Go/No-Gorelease verdict from a confidence score built on 4 weighted quality signals
